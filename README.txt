My Personal Tool Kit V43 — PWA

Upload the contents of this folder (not the ZIP itself) to the root of your GitHub Pages repository. Ensure index.html, manifest.webmanifest, sw.js and icons/ are all uploaded. Enable GitHub Pages in repository Settings > Pages. Open the HTTPS GitHub Pages address in Chrome on Android or Chrome/Edge on Windows and select Install app or Add to Home screen. Visit the page once online to cache it for offline use.

Note: Data is stored in each browser/device separately. Back up data before clearing site storage or switching devices. Online fonts and external integrations may not work offline. GitHub Pages is public; do not upload confidential inventory or passwords.

Upload the CONTENTS of this folder to the root of a GitHub Pages repository or HTTPS host. Open the published index.html in Chrome or Edge, then select Install app / Add to Home screen. Opening index.html directly as a local file does not activate the service worker. Core app files are cached for offline use after first online load. Some third-party libraries and fonts referenced by embedded apps require internet access unless previously cached by the browser. Existing browser storage is origin-specific: moving to a new domain does not migrate saved data. Back up your inventory before changing hosting domains.

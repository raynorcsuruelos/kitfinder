PWA deployment: Upload index.html, sw.js, manifest.webmanifest and the icons folder together to the root of your GitHub Pages site. Open the HTTPS site in Chrome on Android, then use browser menu > Add to Home screen / Install app. Open once online before using offline. Some external resources and online-only integrations may still require internet. IMPORTANT: This HTML contains your embedded backup data. Do not publish sensitive data or password-protected content to a public repository; client-side admin passwords do not secure the downloadable HTML.
